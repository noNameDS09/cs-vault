# Data Structures & Algorithms (DSA)

This directory contains a structured collection of Data Structures and Algorithms (DSA) resources, including theoretical concepts, solved problems, and organized references. It is designed to support learning, interview preparation, competitive programming, and strengthening problem-solving skills through both conceptual understanding and practical implementation.

## Directory Structure

```text
.
├── Solved
├── Theory
└── Leetcode Solved List.md
```

## Contents

### Solved

Contains detailed solutions to DSA problems from various platforms and sources. Each problem is organized with its corresponding solution, explanation, algorithm, complexity analysis, and, where applicable, multiple approaches or optimizations.

Typical structure:

```text
Problem Statement
└── Solved
    └── 1_TwoSum.md
```

Each solution may include:

* Problem description
* Approach and intuition
* Algorithm explanation
* Time and space complexity analysis
* Implementation details
* Alternative or optimized solutions
* Edge cases and observations

### Theory

Contains comprehensive notes on DSA concepts, including data structures, algorithms, problem-solving techniques, and theoretical foundations. The documentation is intended to build a strong conceptual understanding before applying these concepts to coding problems.

Topics may include:

* [Trees and Binary Search Trees](obsidian://open?vault=DSA&file=dsa%2Ftheory%2FBinary%20Tree%20Templates)

* Graphs
* Tries
* Recursion and Backtracking
* Divide and Conquer
* Greedy Algorithms
* [Dynamic Programming](obsidian://open?vault=DSA&file=dsa%2Ftheory%2Fdp%20claude)
* Sliding Window
* Two Pointers
* Binary Search
* Graph Traversal (BFS/DFS)
* Shortest Path Algorithms
* Minimum Spanning Trees
* Union-Find (Disjoint Set Union)

* Bit Manipulation
* Mathematical Algorithms
* String Algorithms

* Complexity Analysis and Algorithm Design

### SOLVED LIST.md

Acts as a centralized index of all solved problems in the repository. Each entry links directly to the corresponding solution (`Solved/answer.md`), making it easy to browse, search, and revisit completed problems.

The index may also include:

* Problem title
* Difficulty level
* Topic(s)
* Source or platform
* Status
* Link to the solution
* Notes or key concepts used

## Purpose

The goal of this directory is to maintain a well-organized repository of DSA knowledge and solved problems, serving as a long-term reference for learning, interview preparation, competitive programming, and continuous improvement in algorithmic problem solving.
