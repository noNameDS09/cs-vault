# 877. Stone Game

## Problem Statement

Alice and Bob play a game with an even number of piles of stones arranged in a row. Each pile contains a positive integer number of stones, where `piles[i]` represents the number of stones in the `i`th pile.

The goal is to finish the game with **more stones** than the opponent. The total number of stones is **odd**, so there will never be a tie.

The game is played as follows:

- Alice goes first.
- On each turn, a player removes the **entire** pile from either the **beginning** or the **end** of the row.
- The game continues until all piles have been removed.
- The player with the most stones wins.

Assuming both Alice and Bob play **optimally**, return:

- `true` if Alice wins.
- `false` otherwise.

---

## Examples

### Example 1

**Input**

```text
piles = [5,3,4,5]
```

**Output**

```text
true
```

**Explanation**

```text
Alice starts by taking the first pile (5).

The remaining piles are:
[3,4,5]

If Bob takes 3:
Alice takes 5 and wins with 10 stones.

If Bob takes 5:
Alice takes 4 and wins with 9 stones.

Thus, Alice can always guarantee a win.
```

---

### Example 2

**Input**

```text
piles = [3,7,2,3]
```

**Output**

```text
true
```

---

## Constraints

```text
2 <= piles.length <= 500
piles.length is even.
1 <= piles[i] <= 500
sum(piles[i]) is odd.
```

## Code

1. Since we have to calculate the difference between Alice and Bob's total stones.
2. If Alice has more stones she wins
3. Else Bob wins

```python
class Solution:
    def stoneGame(self, piles: List[int]) -> bool:
        n = len(piles)

        @cache
        def solve(i, j):
            if i == j:
                  return 0
            return max(
                piles[i] - solve(i+1, j),
                piles[j] - solve(i, j-1)
            )              
        
        return solve(0, n-1) > 0
```
